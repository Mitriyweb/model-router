Model Router

Welcome to Model Router

An Anthropic-compatible proxy that lets Claude Code run on 10 free-tier and local LLM providers instead of the paid Claude API.

Quick Installation

Install model-router binary with one command:

curl -fsSL https://raw.githubusercontent.com/Mitriyweb/model-router/main/install.sh | bash

Or install via Bun:

git clone https://github.com/Mitriyweb/model-router.git
cd model-router
bun install
bun run build

Configuration

Copy .env.example to .env and fill in any keys you have:

cp .env.example .env

Example configuration for GitHub Models:

GITHUB_TOKEN=ghp_...
GITHUB_MODELS_MODEL=gpt-4o
GITHUB_MODELS_RPM=15
GITHUB_MODELS_TPM=64000
GITHUB_MODELS_RPD=150

Usage

Start the proxy:

model-router

Or using Bun:

bun run start

Connect Claude Code:

ANTHROPIC_BASE_URL=http://localhost:8787 ANTHROPIC_API_KEY=dummy claude

Development

Run with hot reloading:

bun run dev

Run full validation:

bun run validate

Compile standalone binary:

bun run build
